# Siding Vision API

Маленький сервер, который держит ваш Anthropic API-ключ и распознаёт размеры дома по 4 фото — так, чтобы ключ никогда не попадал в браузер.

## Быстрый деплой на Render.com (бесплатно)

1. Зарегистрируйтесь на [render.com](https://render.com), «New» → «Web Service».
2. Загрузите эту папку (или свяжите с гит-репозиторием, куда её закинете).
3. Build command: `npm install`
4. Start command: `npm start`
5. В разделе **Environment** добавьте переменную:
   - `ANTHROPIC_API_KEY` = ваш ключ (начинается на `sk-ant-...`), получить можно на [console.anthropic.com](https://console.anthropic.com/settings/keys)
6. Deploy. Через пару минут получите адрес вида `https://siding-vision-api.onrender.com`.
7. Проверьте: откройте `https://ваш-адрес/health` — должно вернуть `{"ok":true}`.

## Локальный запуск

```bash
npm install
export ANTHROPIC_API_KEY=sk-ant-...
npm start
```

Сервер поднимется на `http://localhost:3000`.

## Подключение к калькулятору

В артефакте «Калькулятор сайдинга» в блоке «Фото дома → авторасчёт» есть поле **«Свой сервер (API endpoint)»** — вставьте туда адрес сервера (без `/estimate` на конце, просто `https://ваш-адрес`). Калькулятор сам обратится к `<адрес>/estimate`.

## Что делает `/estimate`

Принимает `multipart/form-data`:
- `photos` — до 4 файлов-фото (порядок: спереди, сзади, слева, справа)
- `refHeight` — известная высота стены в метрах (число)

Возвращает JSON:
```json
{
  "walls": [{"label": "Фасад спереди", "w": 8.2, "h": 3},  ...],
  "openings": [{"label": "Окна", "qty": 6, "w": 1.3, "h": 1.4}, {"label": "Двери", "qty": 1, "w": 0.9, "h": 2.1}],
  "outerCorners": 4,
  "innerCorners": 0,
  "notes": "..."
}
```

## Стоимость и безопасность

- Каждый вызов `/estimate` расходует ваш баланс Anthropic API (обычно доли цента — единицы центов за 4 фото).
- Ключ хранится только в переменной окружения сервера — никогда не отдаётся клиенту.
- Если планируете открыть калькулятор посторонним людям — добавьте свою защиту от злоупотреблений (лимит запросов, авторизацию), иначе кто угодно сможет гонять фото через ваш ключ.
